# CosmoSats Advanced Production API

Бэкенд-модуль для проектирования устойчивой спутниковой группировки и оценки доступности связи, разработанный в рамках КосмоХакатона 2026.

## Структура проекта (`backend/`)
1. **`geometry.py`** — математическая модель орбитального движения, расчета координат спутников и наземных пунктов, проверки геометрии видимости и межспутниковых линий (ISL).
2. **`router.py`** — модуль маршрутизации. Реализует поиск путей на основе графа с использованием **BFS (поиск в глубину)**, а также проверку валидности существующих маршрутов, перестроение при обрывах и диагностику причин сбоев.
3. **`analyzer.py`** — модуль суточной симуляции, оптимизированного сохранения состояний, сравнения сценариев, анализа устойчивости (моделирование отказов каждого аппарата) и автоподбора орбитальных параметров.
4. **`main.py`** — главная точка входа FastAPI, предоставляющая REST API для интеграции с фронтендом и сценарным редактором.

## Инструкция по запуску на Windows

1. Откройте командную строку (`cmd`) или `PowerShell` в корневой папке проекта.
2. Создайте виртуальное окружение Python:
   ```cmd
   python -m venv venv
   ```
3. Активируйте виртуальное окружение:
   * В командной строке (`cmd`):
     ```cmd
     venv\Scripts\activate.bat
     ```
   * В `PowerShell`:
     ```powershell
     .\venv\Scripts\Activate.ps1
     ```
4. Установите необходимые зависимости:
   ```cmd
   pip install -r requirements.txt
   ```
5. Перейдите в папку с бэкендом и запустите сервер разработки:
   ```cmd
   cd backend
   uvicorn main:app --reload --port 8000
   ```

## Инструкция по запуску на Linux (Ubuntu / Debian)

1. Откройте терминал в корневой папке проекта и установите системные пакеты Python:
   ```bash
   sudo apt update
   sudo apt install python3-pip python3-venv python3-dev -y
   ```
2. Создайте виртуальное окружение:
   ```bash
   python3 -m venv venv
   ```
3. Активируйте виртуальное окружение:
   ```bash
   source venv/bin/activate
   ```
4. Обновите `pip` и установите зависимости проекта:
   ```bash
   pip install --upgrade pip
   pip install -r requirements.txt
   ```
5. Перейдите в папку с бэкендом и запустите сервер:
   ```bash
   cd backend
   uvicorn main:app --reload --port 8000
   ```

## Проверка и работа с API
После успешного запуска сервера:
* Интерактивная документация **Swagger UI** доступна в браузере по адресу: **`http://localhost:8000/docs`**
* Вы можете загружать сценарии через эндпоинт `POST /api/load`, изменять параметры конфигурации через `POST /api/update-config` и запускать аналитические расчеты.
